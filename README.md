I learn unfamiliar things by throwing myself into them, then turn what I learn into clearer explanations, better tools, and repeatable systems. I like working between disciplines and seeing a problem from both the expert's perspective and the beginner's.

Portfolio: **[krisstruble.com](https://krisstruble.com)**

**What I build here**

Automation, flexible tools, and prototypes built with AI that eventually become tools that don't need AI to be useful. I'm particularly interested in making existing tools more useful, adaptable, and easier to work with.

**On the bench**

- **AutoHotkey scripts:** currently written in v1, gradually moving toward v2 *(coming)*
- **Free Resume Formatter:** a browser tool that gives a resume a clean, consistent starting format *(coming)*
- **Touch Up:** a small, open-source visual editor for websites: open a site, edit it visually, save back to real files *(in progress)*
- **Block Writer:** a local-first, block-based writing workspace on top of an Obsidian vault, where your files stay the source of truth *(in progress)*
- Older small tools: [CopyAsText](https://github.com/Messyhairkris/CopyAsText) · [Window_size_tester](https://github.com/Messyhairkris/Window_size_tester) · [Homebrew Notion widgets](https://github.com/Messyhairkris/Homebrew_Notion_widgets)

I also have a few larger tools in development around 3D capture and publishing, reading and collaboration, and communication for small teams. These include experiments with splats, photogrammetry, e-ink and e-readers, and ways to help small groups build and share things together.
